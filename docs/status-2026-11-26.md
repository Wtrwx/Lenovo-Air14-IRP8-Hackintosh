# 2026-11-26 隔空投送与首份 EFI

实机为联想小新 Air14 IRP8（i5-1340P、AX211，Wi-Fi `8086:51F1`、蓝牙 `8087:0033`），macOS Tahoe 26.7.2（25G332），OpenCore 1.0.8。

初次试装已加载无线组件并建立 `awdl0`。复测时 `sharingd` 收到了附近设备的端点，并将其交给 Rapport 发现。`rapportd` 此时无法获取本机 IDS Correlation Identifier。

内置 EFI 部署启用了 `PlatformInfo → UpdateNVRAM`，使用本机原有的设备标识。重启后核实四项无线组件已加载、`awdl0` 存在，系统日志记录了隔空投送**发送和接收各成功一次**。

| 组件 | 版本 |
| --- | --- |
| ForbiddenItlwm | `0.7.0-alpha.4` Tahoe |
| IntelBluetoothFirmware | `2.5.3` |
| BlueToolFixup | `2.7.3` |
| BTLEAdvFixup | `0.9.8` Tahoe |

本次实测覆盖双向传输。更大文件、长睡眠后回连及连续运行稳定性待验证。另已确认系统设置中的 Apple 账户登录及 iCloud 账户保存。[上游无线驱动版本说明](https://github.com/retropineaple/ForbiddenItlwm/releases/tag/v0.7.0-alpha.4)
