# 已知问题

## GPU 稳定性

已经观察到 RCS 渲染队列在 batch buffer 中挂起，随后 WindowServer 主线程超过 40 秒未响应，用户需要强制重启。系统动画、应用和系统设置也存在反复卡顿。

目前不能把挂起归因于某个应用、CPU 调度或 120Hz。120Hz 显示 watermark 的时钟单位换算已修正，提交及实际读回检查通过；尚未证明这项修正与 RCS 挂起有直接因果关系。另已记录 VCS0 视频编码队列挂起，触发原因未确认。GPU 稳定性与界面卡顿仍未解决。

WindowServer 的内存统计还出现过异常大数值和持续增长，仍需区分真实分配、表面生命周期和驱动记账问题。

远程桌面的屏幕采集与硬件视频编码路径尚不可用：已观察到远端无画面、VideoToolbox 编码等待及界面卡顿。视频编码引擎挂起后，恢复路径还会反复等待并跳过无关联通道的重启。停止应用不保证清除已挂起的驱动状态；不能把原生 UVC 预览可用视为硬件编码或远程桌面已受支持。

[NativeAvcCompat](../sources/NativeAvcCompat/README.md) 为原生快速 H.264 编码路径准备了 SPS 布局转换。精确 donor 的 CPU 回放可重现未转换输入导致 slice 行坐标翻倍，并验证转换后的边界；实机编码与故障负载仍待验收，不能据此认定 RCS 挂起或 GPU reset 恢复已修复。

## 外接显示与睡眠

当前必须保留 `-wex-edp-panel-only`。这个策略只允许符合条件的内置 eDP 面板，禁用 HDMI、DisplayPort 及 USB-C 视频输出。直接移除曾导致启动黑屏；不能据上游其他机型的兼容情况认定本机外接输出已经可用。

日常开合盖已经确认可用，完整睡眠、深度睡眠及所有唤醒场景仍未验证。

## 外设

- ALC257 已通过 AppleALC / SimpleHDA、layout 101 暴露 CoreAudio 设备，内置扬声器实际出声已确认。音量、静音、耳机输出和耳麦输入仍待分别验收；设备名中的“内置麦克风”不代表 Intel SST 数字麦克风已受支持。
- 蓝牙当前停用；此前启动失败的最后画面出现过 bluetoothd，但根因并未确认。
- 原生 UVC 摄像头的实际预览、应用访问和 90 秒持续原始帧采集已验证，无需额外摄像头驱动。视频通话、视频编码和长时间使用未验证；原始帧测试也出现过较长帧间隔。
- USB-C 扩展坞的普通 USB 枚举不等于 Thunderbolt NHI、雷电热插拔或 USB-C 视频已支持。
- CPU 封装温度已验证读数、负载变化和重启持久性；逐个 P/E 核的独立温度覆盖尚未完整验证。温度插件不提供风扇转速；本机 RPM 接口和电源键响应仍需适配。未发布未经核对的 EC 手动调速方案。
- Fn 功能键尚未完成验证或修复。
- Apple 账户和 App Store 登录故障尚未定位。仓库不包含可共用的机器身份数据。
