# NativeAvcCompat

Darwin 25.6.0 と実デバイス Intel 8086:A7A0 を対象とする、Tiger Lake VA donor
のプログレッシブ H.264 VDEnc 経路向け実験的互換アダプターです。拡張 SPS
レイアウトを、この経路が読み取るレイアウトに変換します。ドライバー識別情報、
実行コード、既存コンパニオン、画像サイズ、スライス境界を検証し、未対応の入力は
GPU への投入前にエラーを返します。
ネイティブコマンドの画像サイズとスライスアドレスの上限に収まるプログレッシブ画像のみを許可します。

CPU テストでは指定 donor のスライス座標が二倍になる問題を再現し、変換、呼び出し元
メモリーの分離、完了時の出力を検証します。実機でのエンコード、リモート画面、
長期的な GPU 安定性は**未検証**です。別のレンダー停止や GPU リセット復旧の修正
ではありません。
導入した候補でも実際のリモート操作は失敗しています。有界の状態メッセージにより、
モジュールのマッピング、実行時ガードの通過、実際のSPS変換を区別します。

次のコマンドでビルドします。

```sh
python3 build.py --donor /path/to/AppleIntelTGLGraphicsVADriver.bundle \
  --output /path/to/new-private-directory
```

サニタイザーテストと CPU のみの
donor 再生を実行し、ローカル署名の候補バンドルを生成してコンパニオンのリンクを
確認します。インストール、再起動、EFI の変更、VA ドライバーの読み込みは行いません。
復元用に現在の VA バンドル全体を正確にバックアップし、管理された実機検証でのみ
候補を使用してください。

Apple バイナリーと生成バンドルは非公開のビルド入出力です。このディレクトリーでは
独自ソースのみを MIT ライセンスで配布します。

ドライバーのパッケージ構成とコンパニオン互換性について、
[WhateverXe Graphics](https://github.com/b00t0x/WhateverXe-Graphics) の成果を基盤としています。
